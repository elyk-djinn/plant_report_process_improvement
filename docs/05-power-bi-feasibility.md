# 5. Power BI feasibility

## Question

Could the Excel dashboard later move to Power BI, so refresh and sharing need no manual work?

## What I did

1. Learned Power BI fundamentals and built a sample dashboard that replicated the existing Excel views.
2. Improved the sample: cleaner card settings, a consistent color scheme, and relationships between tables.
3. Looked at folder queries, slicers and refresh limits.
4. Compared how the dataset behaves with unstandardized versus standardized raw data.

## Findings

- A standard data format is what makes Power BI practical. Tables with the same keys relate cleanly, and the same visuals work across departments.
- Production and quality data blocked a complete move, because their layouts did not fit the standard format yet.
- The Excel redesign is the right first step. It fixes the data structure that Power BI would also need, so nothing built now is thrown away.

## Status

Feasibility work was completed. A full transition was left for a later phase.
