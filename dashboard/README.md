# Redesigned plant report workbook

`plant_report_dashboard.xlsx` is the workbook from the process improvement project. It contains the redesigned dashboard, the control sheets with pivot tables, a `GUIDE` sheet with definitions, and the standardized raw data sheets.

All data in this workbook is anonymized and illustrative.

## How to read it

1. Start with `GUIDE` for definitions and the color coding of sheets.
2. Open `DASHBOARD` to see the redesigned report, and try the month and client type slicers.
3. Look at `DASHBOARD PIVOT TABLES` and `DASHBOARD_DATA` to see how the dashboard is fed.
4. Open any `*_RAW` sheet to see the standard raw data format, and `LOOKUP` for the category tables.
5. `LEGACY DASHBOARD` shows the older static layout for comparison.

Some sheets are large. The workbook is about 7 MB, so it can take a moment to open.
